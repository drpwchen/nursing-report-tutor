# 護理進階報告 AI 家教

照花蓮慈濟護理部的評分表，帶你一步一步完成 **讀書報告（以實證為基礎）**、**實證報告**、**Grand round 案例分析（人形圖）** 的 AI 家教。
2026-10-27 課堂上現場做出來的，送給你帶回家用。

> ⚠️ **病人資料不貼進任何 AI。** 要問個案，先改寫成一般化的臨床問題（例：「骨科術後長者夜間自行下床的跌倒預防」）。

## 這個家教其實是一個資料夾

打開 [nursing-report-tutor](nursing-report-tutor/) 就會看到，裡面全部是**文字檔**和一支**程式**：

| 檔案 | 是什麼 |
|---|---|
| [SKILL.md](nursing-report-tutor/SKILL.md) | 家教的說明書：它是誰、先問什麼、怎麼帶、四條紅線。==AI 讀了這份就變成家教== |
| [規則.md](nursing-report-tutor/規則.md) | 晉升要求、用 AI 的規定、病人資料紅線、揭露範本 |
| [ISO與範本.md](nursing-report-tutor/ISO與範本.md) | 三份評分表逐項、審查通過報告長什麼樣、人形圖格式（單位 2026-10-19 提供，整理成文字） |
| [範例-讀書報告.md](nursing-report-tutor/範例-讀書報告.md)、[範例-實證報告.md](nursing-report-tutor/範例-實證報告.md) | 照評分表寫的虛構跌倒範例：讓 AI 知道「好的長什麼樣子」 |
| [scripts/check_citations.py](nursing-report-tutor/scripts/check_citations.py) | 對引用的程式：內文引用和參考資料有沒有對上。==程式每次答案都一樣== |

AI 是讀文字來理解世界的。你想讓它變成什麼樣的幫手，就寫一份文字給它——這就是這個資料夾。

## 裝到你的 AI 裡（選一種）

- **Claude**：下載 `nursing-report-tutor.zip` → Claude 左下角「設定」→ 先在「功能（Capabilities）」打開「程式碼執行」→「自訂（Customize）」→「技能（Skills）」→ ＋ → 上傳。
- **ChatGPT**：新增一個「專案」→ 把 `SKILL.md` 全文貼進專案的「指示」→ 把 `規則.md`、兩份範例、`ISO與範本.md`、`scripts/check_citations.py` 共 5 個檔上傳成專案檔案。
- **都沒有**：開一個新對話，把 `SKILL.md` 全文貼上、送出，也能用（每次新對話要再貼一次）。

一步一步的畫面說明：[怎麼裝起來.md](怎麼裝起來.md)

## 它會幫你、不會幫你

| 它會帶你做 | 它不會做（要你自己來） |
|---|---|
| 把臨床疑問拆成 PICO | 決定要問什麼 |
| 想中英文關鍵字、MeSH、搜尋字串 | 列出文獻（AI 常編出不存在的文獻） |
| 教你記搜尋紀錄、看證據等級 | 決定證據等級 |
| 把你貼的文獻整理成證據表，每格附出處 | 替你讀完不核對 |
| 用程式對內文引用和參考資料、檢查 APA | 寫護理措施、評值、結論 |

## 讓它越來越好

它哪裡不合你的意，就改 `SKILL.md` 裡的文字——改文字就是在改它。做法見 [自己改進它.md](自己改進它.md)。
想用同樣的方法做別的幫手（衛教、儀器操作、新人訓練）：[自己做一個.md](自己做一個.md)。

## 用了 AI 要寫出來

用了 AI，在報告的致謝（Acknowledgement）段寫一句話就好。例句在 [規則.md](nursing-report-tutor/規則.md) 第 4 節，措辭可以請 AI 幫你調。
